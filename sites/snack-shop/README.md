# 宿舍补给站 · 零食泡面水果

两个页面，两种身份：

| 页面 | 谁用 | 要不要登录 |
| --- | --- | --- |
| `index.html` | 顾客，扫码点单 | **不用注册、不用登录**，打开就能点 |
| `login.html` | 你自己，商家登录 | 账号 **gyq / root** |
| `admin.html` | 商家后台 | 登录后才进得去，没登录会自动跳回 `login.html` |

顾客下单后，订单直接出现在商家后台（8 秒自动刷新），你接单、送货、点「已送达」，营业额自动累加。

收款：后台上传你的微信收款码，顾客付完点「我已付款」，你确认收款 —— 不用营业执照，钱直接进微信零钱。

通知：顾客下单、付款时自动发邮件到 **3154067760@qq.com**（可改）。

三个页面互相都有入口：顾客页底部有「商家登录」，登录页有「← 返回点单页」，后台右上角有「顾客页」，点「退出」回到登录页。

## 一、怎么启动

需要电脑上装了 Node.js（你已经有 v24）。

**最简单**：双击 **`启动服务器.bat`**，会弹出一个黑窗口，别关它。

或者命令行：

```powershell
cd "这个文件夹的路径"
node server.js
```

看到这样的提示就成功了：

```
宿舍补给站 已启动
顾客点单：http://192.168.1.8:3000/
商家登录：http://192.168.1.8:3000/login.html
商家账号：gyq
```

然后：

- **你自己**：浏览器打开 `http://localhost:3000/login.html`，用 `gyq` / `root` 登录（也可以直接开 `admin.html`，没登录会自动跳到登录页）
- **同学**：同一个 WiFi 下打开 `http://192.168.1.8:3000/`（换成你电脑的 IP，服务器启动时会打印），或者把这个地址生成二维码贴宿舍门

> 第一次启动 Windows 可能会弹「防火墙」提示，选**允许访问**，不然手机连不上。

**关掉黑窗口 = 关店**。关掉之后顾客页面还能打开，但会变成「离线小票模式」（见第六节）。

## 二、商家后台怎么用

登录后是这样：

```
🍜 商家后台  已登录：gyq          ●实时  刷新  退出
┌──────────┬──────────┬────────────┐
│ 待接单 2 │ 今日订单 5│ 今日营业额 ¥68│
└──────────┴──────────┴────────────┘
订单 | 商品
全部 6  待接单 2  配送中 1  已完成 3  已取消 0
```

### 订单

每笔订单显示：状态、订单号、时间、商品和数量、送到几栋几号、电话、备注、金额。

操作按钮：

| 订单状态 | 你能点 |
| --- | --- |
| 待接单 | **接单** → 变成「配送中」；**取消**（比如卖完了） |
| 配送中 | **已送达** → 完成并计入营业额；**取消** |
| 已完成 / 已取消 | **删除记录**（只是清列表，不影响已记的营业额以外的数据） |

- 「📞 打电话」直接拨给顾客（手机上最有用）
- 页面每 8 秒自动刷新，不用手动点；有新订单会弹提示，浏览器标签标题会显示 `(2) 待接单 · 商家后台`
- 手机浏览器也能用，建议把 `admin.html` 加到主屏幕（登录一次能保持 12 小时）

### 商品

- **改价**：直接改数字，改完点旁边空白处就保存，顾客端立刻生效
- **库存**：每行都有「库存」输入框，改成多少就是多少。顾客下单自动扣、取消订单自动加回来；库存 0 时顾客端显示「售罄」不能买
- **售罄**：勾上「售罄」，顾客页那一行会变灰、显示「售罄」，不能再加购（和库存 0 效果一样）
- **新增**：展开「＋ 新增商品」，填名字、价格、分类、规格、单位、图标（一个 emoji）即可
- **换图**：点商品左边的小图（或「换图」），选一张照片，自动压缩到 1200px 上传；顾客页、购物车里都会显示这张照片
- **还原**：有照片时点「还原」，换回原来的 emoji
- **删除**：点 ✕，直接从菜单消失

### 收款码

打开后台「收款码」页，上传你的微信收款码截图（微信 → 我 → 服务 → 收付款 → 二维码收款），
手机截图直接选就行，会自动压缩到 900px 再上传。

上传后整套收款流程是这样：

```
顾客结算 → 成功页显示 [收款码 + 应付金额 + 订单号]
        → 顾客扫码付款，备注订单号
        → 点「我已付款」
        → 你后台这单出现「待确认收款」＋「确认收款」按钮
        → 你核对微信账单后点「确认收款」→ 变绿色「已收款」
```

- 没有上传收款码时，顾客成功页只显示「加我微信转账」，不影响下单
- 换码：再上传一次覆盖；删除：点「删除」，顾客端就看不到二维码了
- 收款直接进你的微信零钱，平台不经手，也没有手续费和提现费

⚠️ 个人收款码**没有自动对账**：顾客说付了，系统只能记一笔「待确认」，钱到底到没到要你看微信账单。
金额大的单子建议扫一眼；想做到「付款自动确认」，只能接官方微信支付，见下面。

### 邮件通知

新订单、顾客点「我已付款」时，自动发一封邮件到 **3154067760@qq.com**（地址写在 `data.js` 的 `email` 里）。

**第一次用，先拿 QQ 邮箱的「授权码」**：

1. 电脑打开 mail.qq.com 登录你的 QQ 邮箱
2. 右上角「设置」→「账号」（新版是「账号与安全」→「安全设置」）
3. 找到「POP3/IMAP/SMTP…服务」，开启 **POP3/SMTP 服务**
4. 按提示发短信验证，会给你一串 16 位**授权码**（不是 QQ 密码，只显示一次，记下来）
5. 回到商家后台 →「收款码」页 → 下面的「邮件通知」：
   - 收件邮箱：`3154067760@qq.com`
   - 发件邮箱：留空（默认和收件相同，必须是你自己的 QQ 邮箱）
   - 授权码：粘贴刚才那串
   - 点「保存」，再点「发送测试邮件」
6. 去邮箱（连垃圾箱一起看）找「【测试】宿舍补给站 邮件通知」

之后：

| 事件 | 邮件内容 |
| --- | --- |
| 顾客下单 | 主题「新订单 #261025-1234 ¥12.50」，正文有商品、楼栋房号、电话、备注 |
| 顾客点「我已付款」 | 主题「顾客说已付款 …」，提醒你核对账单、去后台确认收款 |

两个勾选框可以单独关掉某类通知；取消「开启邮件通知」就全部停止。发送失败的原因显示在设置页底部。

注意：

- 授权码存在 `data/settings.json` 里，**别把这个文件发出去**
- 电脑要能连外网 465 端口，校园网封了就会超时（设置页会显示失败原因）
- 换邮箱或重置授权码后，回来重新填一次
- 发信是后台异步的，不会拖慢顾客下单

<details>
<summary>想接官方微信支付（自动确认到账）需要什么</summary>

微信支付的 API 只对**商户号**开放，商户号必须有营业执照，个人办不了：

1. 办个体工商户执照（当地市场监管局，线上可提交，需要经营场所证明）
2. 申请微信支付商户号（pay.weixin.qq.com），绑定 AppID
3. 一个**公网 HTTPS 域名**（回调 `notify_url` 必须公网可访问，内网 IP 不行），域名要备案
4. APIv3 密钥、商户 API 证书（`apiclient_key.pem`）、平台证书
5. 费率约 0.6%，T+1 到银行卡

代码上要在 `server.js` 增加「统一下单 → 生成二维码 → 回调验签解密 → 更新订单」，
再配一个前端轮询。这些功能我随时可以加，但没有真实商户号和公网域名跑不通。

## 三、账号与安全

账号写在 `server.js` 顶部，改完**重启服务器**生效：

```js
const LOGIN = { username: 'gyq', password: 'root' };
```

建议改成只有你知道的密码。`root` 这种密码只适合宿舍内网，别把服务器直接扔到公网上。

现在的安全措施：

- 密码错了 8 次，同一台设备锁 1 分钟
- 登录用 HttpOnly Cookie，12 小时后自动失效（重启服务器所有人重新登录）
- 订单、改价这些接口都必须登录才能调用；顾客只能「下单」，看不到别人的订单和手机号
- 数据文件 `data/` 禁止通过网页直接访问，也不会被上传到 git（见 `.gitignore`）

## 四、顾客看到什么

手机上就是一个扫码点单页，没有任何注册步骤：

```
宿舍补给站                 ● 营业中
零食 · 泡面 · 水果 · 饮料   09:00–23:00
全部  零食  泡面  水果  饮料
─────────────────────────────
🍟 乐事薯片 原味          ⊕
   70g/袋 · 已售 386  ¥5.5
─────────────────────────────
🛒²  ¥12.50          去结算
```

点「去结算」→ 填楼栋、宿舍号、手机号、备注 → 提交 → 弹出「订单已发送给商家」和小票。

顾客端规则：

- 每行价格右边显示「库存 20」，剩 5 件以内变成橙色的「仅剩 3 袋」，0 件显示「没货了」
- 满 ¥8 起送，满 ¥15 免配送费，不满就点不了结算
- 购物车存在手机本地，刷新不丢
- 售罄或库存 0 的商品显示「售罄」，加不了；加购超过库存会被拦下
- 价格、库存、起送价、配送费全部以服务器为准，顾客改不了
- 顶部「营业中 / 休息中」按 `data.js` 里的营业时间自动显示

## 五、改商品、改店铺设置

### 店铺设置（微信号、起送价、楼栋……）

改 **`data.js`** 最上面：

```js
window.SHOP = {
  name: '宿舍补给站',
  minOrder: 8,          // 起送价
  deliveryFee: 1.5,     // 配送费
  freeDeliveryAt: 15,   // 满多少免配送费
  openHour: 9,
  closeHour: 23,
  phone: '138-0000-0000',   // ← 改成你的
  wechat: 'sushe_buji',     // ← 改成你的
  buildings: ['1栋', '2栋', ...],
};
```

保存后**不用重启**，顾客刷新页面就是新的（楼栋下拉提示也会跟着变）。

### 商品

第一次启动时，`data.js` 里的 42 个商品会被复制到 `data/products.json`（库存默认 20）。**之后以商家后台的修改为准**，`data.js` 里的商品列表不再生效。

- 平时加菜、改价、改库存、售罄 → 用后台「商品」页
- 想恢复到最初的 42 个商品 → 停服务器，删掉 `data/products.json`，再启动

### 配色

- 顾客页：`styles.css` 最上面的 `--accent`
- 商家页：`admin.css` 最上面的 `--accent`

## 六、没有服务器会怎样（离线模式）

直接双击 `index.html`（不启动服务器）也能用，但要明白区别：

| | 启动服务器 | 只双击 index.html |
| --- | --- | --- |
| 顾客能点单 | ✅ | ✅ |
| 订单进商家后台 | ✅ 自动 | ❌ 不会 |
| 顾客提交后 | 提示「已发送给商家」 | 显示小票，要顾客自己复制发你微信 |
| 商家后台 | ✅ 能登录 | ❌ 打不开（会提示连不上服务器） |
| 商品价格同步 | ✅ 改完立即生效 | ❌ 各看各的 |

所以「只发文件给同学」只适合临时用；想躺着收单，就把服务器跑起来。

## 八、让不在同一 WiFi 的同学也能点

现在的地址是局域网 IP，只在本校 WiFi 内有效。要公网访问，两个办法：

1. **内网穿透**（最简单）：用 cpolar / ngrok / frp 把 `3000` 端口映射出去，得到一个公网地址。
2. **放到云服务器**：买台最低配的服务器，装 Node，把文件夹传上去，`node server.js`，再用 Nginx 反代 + 域名 + HTTPS。

公网使用前请务必：

- 把 `gyq` / `root` 改成强密码
- 用 HTTPS（不然密码和手机号是明文传输）
- 别把 3000 端口直接暴露在公网

## 九、常见问题

**端口被占用？**
换一个端口启动：

```powershell
set PORT=3001 && node server.js
```

然后访问 `http://localhost:3001/`。

**手机打不开？**
1. 手机和电脑要连同一个 WiFi
2. 用启动时打印的那个 `192.168.x.x` 地址，不是 `localhost`
3. Windows 防火墙要允许 Node.js 访问网络
4. 有的校园网开了「AP 隔离」，设备之间互相访问不了，这种情况只能用内网穿透

**订单进来了我没看到？**
保持后台页面开着，8 秒自动刷新；手机浏览器切到后台可能会暂停刷新，回来时会自动拉一次。

**顾客说下单失败？**
看他屏幕上的提示：售罄 / 不满起送价 / 手机号格式，都有明确文案。让他刷新页面再试。

**邮件收不到？**
1. 先在后台点「发送测试邮件」，看底部提示：授权码错 / 超时 / 收件人被拒
2. 授权码要去 mail.qq.com 重新生成（不是 QQ 密码）
3. 看垃圾箱，「宿舍补给站」可能被判成推广邮件
4. 校园网封 465 端口的话，换手机热点试一次

**能加支付吗？**
现在支持「个人收款码 + 我已付款 + 商家确认收款」，不用营业执照，详见第二节的「收款码」。
如果想要「付款后自动确认到账」，必须接官方微信支付，需要个体户执照、商户号和公网 HTTPS 域名，
个人办不了、也测不了；需要的话我可以把代码骨架搭好。
